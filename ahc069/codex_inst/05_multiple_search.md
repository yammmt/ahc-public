# 探索始点の追加

## 目的

グループの配置について, 現状は最初に見つかった空きマス集合を割り当てています.
しかし, これは非効率である可能性があります.

## 実装すること

- Dijkstra 法による探索の始点を, 有効な二グループに対して実施し, よりよいスコア (高いコンパクト度) が得られたマス群を貪欲に割り当てます.
- 有効な二グループの探索方法は, 実装の楽な方法で構いません.
  - 例えば, 左上のマスから愚直なループで連結領域を探索し, 最初に見つかった二領域をそのまま採用してよいです.
- 一度のグループ入力に対し, 実行時間が 1ms を超えた時点で, 追加探索処理は断念します.
  - 全体の実行時間制約が 2,000 ms であり, 今のプログラムの実行時間ではあまり余裕がありません.
